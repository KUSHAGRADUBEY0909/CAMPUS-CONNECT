# CampusConnect — Campus Lost & Found Portal

A responsive, browser-based student project for reporting lost and found items on campus.

## Run it (no installation)
1. Download and extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Try searching, filtering, publishing a report, and viewing contact details.

No Node.js, React, MongoDB, Python, npm, database server, or internet connection is required.

## Features
- Publish Lost or Found reports
- Search by item, location, description, or category
- Filter by report type and category
- Summary counters and contact display
- Browser persistence using `localStorage`
- Responsive layout and sample records

## Technology
- HTML5 for structure
- CSS3 for responsive styling
- Vanilla JavaScript for application logic
- Browser `localStorage` for local persistence

## Important limitation
This is a client-side prototype. Data is stored only in the browser profile on the current device; it is not shared between students or devices. A production version could add a React frontend, API backend, MongoDB, authentication, and moderation.
